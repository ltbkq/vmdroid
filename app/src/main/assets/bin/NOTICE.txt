----------------------------------------------------------------------

  curl -fLLO https://github.com/facebook/zstd/releases/download/v1.5.6/zstd-1.5.6.tar.gz
  sha256sum zstd-1.5.6.tar.gz
  tar xzf zstd-1.5.6.tar.gz
  cd zstd-1.5.6
  NDK=$ANDROID_SDK/ndk/28.2.13676358/toolchains/llvm/prebuilt/linux-x86_64/bin
  # NOTE: the release tarball uses lib/ (the git checkout calls it libzstd/)
  make -C lib libzstd.a -j"$(nproc)" \
      CC=$NDK/aarch64-linux-android26-clang AR=$NDK/llvm-ar
  make -C programs zstd -j"$(nproc)" \
      CC=$NDK/aarch64-linux-android26-clang LD=$NDK/aarch64-linux-android26-clang \
      AR=$NDK/llvm-ar RANLIB=$NDK/llvm-ranlib LDFLAGS="-static"
  # (API26 = minSdk; zstdless/zstdgrep never built — target "zstd" only;
  #  debug symbols stripped by AGP packaging)

Purpose in this app
-------------------
The VMDroid app installs `.img.zst` compressed system images. It performs
streaming decompression by executing this statically linked binary as a
subprocess: `ProcessBuilder(zstd, "-dc")` with the compressed source bytes
fed on stdin (see the header comment of
app/src/main/java/io/github/ltbkq/vmdroid/systemimage/ZstdInflator.kt).

Source path: app/src/main/jniLibs/arm64-v8a/libzstdbin.so
Runtime:     extracted by the package manager at install time into
             nativeLibraryDir (unwritable by the app, 0755 — executable
             under Android 10+ W^X rules; the former assets/bin/zstd →
             filesDir/bin/zstd path was denied with EACCES/error=13 on a
             real device). When the bundled binary is absent, resolution
             falls back to a zstd found on PATH (development-only).
